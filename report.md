# To-Do List - Project Report

## Project Overview
Our project is a simple to-do list website where users can add tasks and remove them once they’re done. The idea is to practice building a basic web app and use Git to manage the code versions and track progress.

## Tools and Technologies Used
- HTML: to build the structure of the web page.
- CSS: to make the page look nice and organized.
- JavaScript: to add the logic like adding and removing tasks.
- Git & GitHub: to manage the code, track changes, and work with branches.

## Task Distribution
Although the project was done by one student, I divided the tasks as if it was a group of 3 people to follow the instructions:
- **Frontend work**: Designing the layout and user interface (HTML & CSS).
- **Logic and functionality**: Writing JavaScript code to add and delete tasks.
- **Documentation and Git management**: Creating this report, handling Git branches and commits.

## Challenges Faced
At first, Git was confusing. I got some errors about my name and email not being set. Also, organizing the branches for each part of the project took a bit of trial and error. Writing the JavaScript part was also tricky because I had to figure out how to remove tasks after adding them.

## Solutions
I solved the Git issue by setting my name and email using commands. I also created three branches: one for the frontend, one for logic, and one for this report. I kept saving my changes by using commits with clear messages so I could go back if anything went wrong.

## Git Workflow
- Created the main repository on GitHub.
- Made 3 branches: `frontend`, `logic`, and `documentation`.
- Worked on each part in its own branch.
- Used `git add`, `commit`, and `checkout` to manage everything.
- All commits had clear messages showing what was done.

## Extra Notes
I learned a lot while doing this project. Git is very useful, and even though it was confusing at first, I feel more comfortable with it now. Also, building the to-do app helped me understand how HTML, CSS, and JavaScript work together.
